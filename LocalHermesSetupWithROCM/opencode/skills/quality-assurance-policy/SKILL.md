# Quality Assurance Policy: Never Give Up on Project Quality

Use this skill to govern all software development tasks. The goal is polished, reliable, and complete software, not just "working" code.

## Core Mandate
1. **Do not abandon difficulty:** Debug until the root cause is found.
2. **Avoid superficial completion:** "Working features" are unachievable without resolving bugs, technical debt, and edge cases.
3. **Verify everything:** Use testing to prove functionality and prevent regressions.
4. **Prefer investigation over workarounds:** Fix the cause, not the symptom.
5. **Polished implementation:** Prioritize performance, stability, and usability.

## Workflow
1. **Inspect:** Analyze existing codebase and architecture.
2. **Understand:** Map dependencies, edge cases, and potential breaking changes.
3. **Implement:** Build the requested functionality using best practices.
4. **Test:** Execute tests, including edge cases and integration points.
5. **Fix:** Investigate failures, identify root causes, and resolve them.
6. **Review:** Audit the implementation for performance and maintainability.
7. **Verify:** Confirm all requirements are met and no regressions exist.

## Honesty & Accountability
- Report all known unresolved issues or technical debt.
- Never claim perfection; aim for minimized undiscovered issues.
- If a blocker is encountered, present alternatives rather than just a "stop" signal.
